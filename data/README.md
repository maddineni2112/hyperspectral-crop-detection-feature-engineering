# Data statement

The project references the Indian Pines hyperspectral benchmark, originally distributed for hyperspectral image classification research. The raw cube and ground-truth files are excluded because they are large benchmark data with separate distribution terms.

Obtain Indian Pines from its documented official/research source, keep the cube and labels outside this repository, and point the notebook to the local files. The expected inputs are a hyperspectral cube and aligned crop/class labels; the report documents the feature and class schema.
