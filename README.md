# Multi-Scale Feature Engineering for Crop Detection from Hyperspectral Images

**Timeline:** December 2025  
**Category:** Main project

This project builds a multi-scale feature pipeline for crop detection from hyperspectral imagery. It combines spectral indices, PCA, texture descriptors, and morphological profiles before comparing supervised classifiers and inspecting spatial prediction behavior.

## Stack

Python, NumPy, Pandas, SciPy, scikit-learn, scikit-image, Indian Pines, PCA, NDVI, NDWI, NDTI, EVI, Gabor filters, LBP, morphological profiles, Random Forest, and SVM.

## Repository contents

- `src/` — notebook/source workflow.
- `report/` — editable project report and figures.
- `data/README.md` — Indian Pines provenance and excluded-data instructions.
